| Kode | Skenario | Hasil yang diharapkan | Aturan/Constraint | Status |

| UJ-02 | Menambahkan nomor anggota yang sudah digunakan | Ditolak, ERROR 1062 | AB-01, `uq_anggota_no` | ✓ |

| UJ-05 | Menambahkan detail eksemplar yang sama dua kali pada peminjaman yang sama | Ditolak, ERROR 1062 | PK `pk_detail_peminjaman` | ✓ |
| UJ-06 | Menambahkan detail dengan kode eksemplar yang tidak terdaftar | Ditolak, ERROR 1452 | FK `fk_detail_peminjaman_eksemplar` | ✓ |
| UJ-07 | Mengembalikan eksemplar yang sama dua kali pada peminjaman yang sama | Ditolak, ERROR 1062 | AB-08, `uq_pengembalian_detail` | ✓ |

**Catatan:** Jalankan pengujian satu per satu. Gunakan `ROLLBACK` setelah setiap uji agar data contoh tidak berubah. Isi kolom Status berdasarkan hasil nyata dari MariaDB/phpMyAdmin.

## 3. Kode SQL Pengujian

### UJ-01 — Peminjaman valid oleh anggota aktif

```sql
START TRANSACTION;

INSERT INTO peminjaman
(id_anggota, id_petugas, tanggal_peminjaman, batas_pengembalian)
VALUES (1, 1, '2026-10-01', '2026-10-08');

SELECT *
FROM peminjaman
WHERE no_peminjaman = LAST_INSERT_ID();

ROLLBACK;
```

## Kode SQL Pengujian

### 1. UJ-01 — Penjualan dengan anggota aktif

```sql
INSERT INTO penjualan
(no_nota_penjualan, tgl_penjualan, id_petugas, id_anggota, bayar_penjualan)
VALUES (
    'PJ-UJ01-0001',
    NOW(),
    (SELECT id_petugas FROM petugas WHERE kode_petugas = 'K01'),
    (SELECT id_anggota FROM anggota WHERE no_anggota = 'A01'),
    30000
);
```

### 3. UJ-03 — Mengubah stok menjadi negatif

```sql
SET stok_barang = -5
```


### 5. UJ-05 — Menambahkan detail penjualan dengan jumlah 0
```sql
INSERT INTO detail_penjualan
(id_penjualan, id_barang, qty_detail_penjualan, harga_satuan_detail_penjualan)
SELECT
    p.id_penjualan,
    b.id_barang,
    0,
    b.harga_jual_barang
FROM penjualan AS p
CROSS JOIN barang AS b
WHERE p.no_nota_penjualan = 'PJ-2609-0142'
  AND b.kode_barang = 'ATK-001';

MySQL menyatakan: Dokumentasi

#4025 - CONSTRAINT `ck_detail_qty` failed for `kopma_106`.`detail_penjualan`
```
